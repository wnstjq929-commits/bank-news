# 🏦 은행 뉴스 브리핑

국내 경제 뉴스에서 **은행 관련 기사만 자동 수집**해, 은행별·주제별·날짜별로 정리하고
각 사건에 대한 **요약 · 은행에 미치는 영향 · 구체적 해결책**을 붙여 보여주는 로컬 대시보드.

## 웹앱으로 실행 (권장)
- **`웹서버.bat` 더블클릭** → 로컬 웹서버가 켜지고 브라우저가 `http://localhost:8787` 로 자동 열립니다.
  - 페이지의 **↻ 새로고침** 버튼이 **실제로 최신 뉴스를 수집**합니다 (파일 모드와 달리 버튼이 살아있음).
  - **같은 Wi-Fi의 폰/태블릿**에서는 서버 창에 표시되는 `http://<이 PC의 IP>:8787` 로 접속하면 됩니다.
  - 종료: 서버 창에서 `Ctrl+C`. (서버가 켜져 있는 동안만 접속 가능)

## 파일 하나로 바로 쓰기 (서버 없이)
- **`index.html` 더블클릭** → 대시보드가 브라우저로 열립니다. (설치 불필요)
  - 상단 **↻ 새로고침** 버튼 · **날짜 선택**(최근 2주치 자동 축적)
  - 카드를 **누르면 펼쳐지며**: 상세 요약 → 📖 용어 풀이(어려운 단어 자동 설명) → ⚠ 은행 영향 → ✅ 해결책
  - 같은 사건은 하나로 묶고 **여러 언론사 원문 링크**를 함께 제공(누르면 원문으로 이동)
  - 은행별/주제별 칩, 제목·내용 검색 지원

## 최신 뉴스로 갱신
- **`새로고침.bat` 더블클릭** → 최신 뉴스 수집 + (로그인 시)AI 분석 + 대시보드 재오픈. 가장 간편.
- 또는 수동:
  ```bash
  node fetch_news.js               # 수집 + 대시보드 재생성
  node fetch_news.js --build-only  # 재수집 없이, 기존 분석만 반영해 재빌드
  ```
- 파이프라인: 수집 → 은행 필터 → 클러스터링 → `analysis.json`(AI 분석) 병합 → `index.html` 생성

## 매일 자동 갱신 (이미 설정됨)
- Windows 작업 스케줄러에 **`BankNewsDaily`** 작업이 등록되어 **매일 오전 7:30**에 `run-daily.bat` 실행.
- `run-daily.bat` 순서: 수집 → 분석대기 목록 생성 → (로그인 시)AI 분석 → 대시보드 재생성.
- 시간 변경/삭제:
  ```powershell
  # 시간 변경 (예: 오전 8시)
  Set-ScheduledTask -TaskName "BankNewsDaily" -Trigger (New-ScheduledTaskTrigger -Daily -At 8:00am)
  # 자동 갱신 끄기
  Unregister-ScheduledTask -TaskName "BankNewsDaily" -Confirm:$false
  ```

## ⭐ 매일 AI 분석 자동화 켜기 (한 번만)
매일 "영향·해결책" AI 분석까지 자동 생성하려면, 로컬 Claude에 **한 번만 로그인**하면 됩니다.
1. **`login-once.bat` 더블클릭**
2. 창이 열리면 `/login` 입력 → 안내대로 로그인 → 창 닫기
- 이후부터는 매일 자동 실행 때 새 기사에 대한 AI 분석이 자동으로 채워집니다.
- (로그인 전에도 수집·요약·분류·원문링크·날짜기능은 무료로 매일 동작합니다. AI 분석만 비어 있음)

## 데이터 소스
- **직접 RSS**(요약 충실): 연합뉴스·연합증시·뉴시스·아시아경제
- **구글뉴스 검색 RSS**(전 언론사, 최근 2주치): 은행명·금리·대출 등 키워드로 폭넓게

## 파일 구성
| 파일 | 역할 |
|------|------|
| `index.html` | 완성된 대시보드 (데이터 내장, 더블클릭 실행) |
| `template.html` | 대시보드 UI 템플릿 (`/*__DATA__*/` 자리에 데이터 주입) |
| `fetch_news.js` | 수집·필터·클러스터링·분석병합·빌드 |
| `make_pending.js` | 아직 분석 안 된 기사만 추려 `_work/pending.json` 생성 |
| `daily_prompt.md` | 무인 AI 분석 시 Claude에게 주는 지시문 |
| `analysis.json` | 기사 id별 AI 분석 결과(요약/영향/해결책) 누적 저장 |
| `store.json` | 최근 30일 기사 누적 저장소 |
| `run-daily.bat` | 매일 자동 실행 스크립트 |
| `login-once.bat` | AI 자동화용 1회 로그인 도우미 |
| `update.log` | 자동 실행 로그 |

## 커스터마이즈
- 추적할 **은행/주제/검색어**: `fetch_news.js` 상단의 `BANKS` · `TOPICS` · `GNEWS_QUERIES` 배열 수정
- 뉴스 **소스 추가/제거**: `DIRECT_FEEDS` 배열 수정
